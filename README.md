# TugQuiz · SL165

Квизы и «Арқан тартыс» для лицея №165 (7–11 классы). Учитель запускает игру на доске, ученики отвечают с телефонов по PIN-коду.

*Developed by Daniyar.*

## Что умеет

- **Аккаунты**: администратор, учителя (регистрация по коду от администратора), ученики (рейтинг, уровни, награды). Играть можно и без аккаунта.
- **Четыре режима**: Арқан тартыс (2 команды, канат), команды по очереди, каждый сам за себя, канат на доске (без телефонов, две половины интерактивной доски).
- **Вопросы**: выбор ответа, верно/неверно, число, свой ответ (учитель может оценить ✓ ½ ✗). Формулы (KaTeX), картинки, видео (YouTube, Vimeo, файл), ссылки, жирный и курсив.
- **ИИ бесплатно**: промт копируется в любой чат (ChatGPT, DeepSeek, Gemini…) и ответ вставляется обратно, или одной кнопкой с бесплатным ключом Gemini/Groq. Можно дать тему, примеры заданий и фото учебника.
- **Генератор примеров** для доски по уровням 7, 8–9 и 10–11 класс.
- **Отчёты**: график каната, сложность вопросов, топ учеников, вклад в команду, печать в PDF.
- Шаблоны по предметам, библиотека квизов коллег, предпросмотр «как ученик», интерактивный гайд и тур по меню.
- Русский и казахский интерфейс.

## Устройство

Node.js 22+ без сборки фронтенда.

| Папка | Что внутри |
|---|---|
| `server/index.js` | HTTP API, раздача сайта, загрузка файлов |
| `server/game.js` | живые игры по WebSocket: лобби, вопросы, очки, канат |
| `server/quizlib.js` | проверка вопросов, оценка ответов, формула очков |
| `server/ai.js` | промт для ИИ и разбор его ответа |
| `server/db.js` | SQLite (встроен в Node), схема таблиц |
| `web/js/pages/` | страницы сайта; `web/js/rope.js` — анимация каната |
| `web/js/kk.js` | казахский перевод (ключ — русская фраза) |

Данные лежат в папке `TQ_DATA` (по умолчанию `./data`): база `tugquiz.db` и загрузки `uploads/`. Для резервной копии достаточно скопировать эту папку.

## Запуск на своём компьютере

**Windows:** двойной клик по `start.bat` — он поставит зависимости, запустит сервер и откроет сайт. В окне будет адрес для телефонов (`http://192.168.x.x:8080`, телефон и компьютер в одной Wi-Fi). Если телефон не открывает адрес, при первом запуске разрешите Node.js доступ в брандмауэре Windows («частные сети»). Файл `index.html` двойным кликом открывать нельзя — сайту нужен запущенный сервер.

Вручную:

```bash
npm install
npm start            # http://localhost:8080
npm test             # автотесты
```

Первый зарегистрированный пользователь становится администратором. Код для регистрации учителей пишется в консоли и виден в разделе «Администратор».

## Выкладка на сервер

Нужен сервер на Ubuntu или Debian с доступом по SSH. Домен не обязателен.

1. Двойной клик по **`Выложить на сервер.cmd`**, введите `логин@IP` сервера (например `root@185.1.2.3`) и дважды пароль сервера.
2. Скрипт отправит последний коммит на сервер в `/opt/tugquiz`, поставит Node.js 22 и Caddy, получит HTTPS-сертификат и включит автозапуск. В конце он покажет адрес сайта: без своего домена это `https://185-1-2-3.sslip.io`.
3. **Обновление:** закоммитьте изменения и снова запустите `Выложить на сервер.cmd`. База и загрузки лежат в `/var/lib/tugquiz` и не трогаются.

Свой домен (например, с [duckdns.org](https://www.duckdns.org)): `powershell -ExecutionPolicy Bypass -File deploy\deploy.ps1 root@185.1.2.3 sl165quiz.duckdns.org`.

Логи: `journalctl -u tugquiz -f`.

## Демо одним файлом (для отправки в WhatsApp)

`demo/TugQuiz-SL165-demo.html` (около 1 МБ) открывается двойным кликом в любом браузере, без сервера и интернета: «Канат на доске» с генератором примеров для 7–11 классов, русский и казахский. Аккаунтов и игры с телефонов по PIN в демо нет, это только на сервере. После изменений сайта пересоберите файл: `node demo/build.mjs`.
